## Run stability
> **Warning:** the runs below are far from their format's median.
>
> Two signatures distinguish a disturbed machine from a slow format. The
> `Tokenizer` column is an identical CPU-bound parse in every HuggingFace
> format, so if it rose with the rest, the machine was disturbed. And
> because formats are interleaved, a disturbance lands on whichever
> formats happen to be running — so flagged runs **clustered in time
> across different formats** are external by construction. A genuinely
> slow format cannot make a different format slow two seconds later.
>
> Repeat the sweep. Do not delete the runs.
